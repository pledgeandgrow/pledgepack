Manage PledgePack plugins — search, install, list, docs (#67, #68, #69)

Usage: pledgepack plugin [OPTIONS] <COMMAND>

Commands:
  search   Search the npm registry for PledgePack plugins
  install  Install a plugin from npm
  list     List installed PledgePack plugins
  create   Scaffold a new plugin project (#68)
  docs     Generate API docs from a plugin source file (#69)
  sign     Sign a plugin file — writes a `<file>.sig.json` trust sidecar that plugin hosts verify at load time (see `plugin_security` config)
  keygen   Generate a fresh Ed25519 keypair for plugin signing
  help     Print this message or the help of the given subcommand(s)

Options:
      --root <ROOT>      Project root directory (default: current directory)
      --config <CONFIG>  Config file path (default: auto-detect pledge.json)
      --strict           Treat config-file problems (unknown / misspelled keys) as errors
  -h, --help             Print help
