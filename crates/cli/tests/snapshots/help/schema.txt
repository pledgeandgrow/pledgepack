Generate JSON Schema for pledge.config.ts / pledge.json Useful for IDE autocompletion and config validation

Usage: pledgepack schema [OPTIONS]

Options:
  -o, --output <OUTPUT>  Output file path (default: stdout)
      --root <ROOT>      Project root directory (default: current directory)
      --config <CONFIG>  Config file path (default: auto-detect pledge.json)
      --strict           Treat config-file problems (unknown / misspelled keys) as errors
  -h, --help             Print help
